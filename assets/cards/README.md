# Imágenes de las cartas

Añade aquí archivos PNG, JPG, JPEG, WebP o GIF, directamente en esta carpeta.
Flutter descubre todas las imágenes del manifest de assets; no hace falta editar código.
Vuelve a ejecutar o generar la aplicación después de añadir imágenes.
Cada partida elige al azar imágenes distintas. Si faltan, completa con letras A–T.
Una imagen = una pareja. Usa nombres distintos y evita duplicar la misma foto.
Las imágenes mantienen su proporción con BoxFit.contain.
